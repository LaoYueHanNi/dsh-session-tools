# DR: 会话目标标记使用稳定 ID

Status: implemented

## Problem

同名或过长标题无法唯一标识选择器选中的会话，标题变更也会使已插入的标记失效。

## Decision

选择器的 chip 和纯文本回退均序列化为包含会话 ID 的普通文本标记，标题只用于显示。模型直接以该 ID 调用 `session_send`；手工输入的标题仍支持查找与消歧。标记不使用原生会话引用，避免注入目标快照。

## Alternatives considered

- **只序列化标题** —— 同名、截断及重命名均会丢失目标身份。

## Consequences

- 代价：模型侧标记包含不易阅读的 ID。
- 换来：目标身份不依赖可变标题，也不引入目标会话读取。
