# 0.1.0

首个发布版本。此前该插件只以本地目录形式安装，本次补齐开源与发版所需的全部工程化。

> 仓库当前仍处于私有阶段：`package.json` 带 `private: true`。转公开后移除该字段，按本文档发布 0.1.0。

## 功能

- **五个跨会话工具**：`session_list`、`session_send`、`session_read`、`session_create`、`session_models`。
- **`session_create` 可指定模型**：可选 `provider` / `model` / `reasoningEffort` 三参，先对照实时模型目录校验（不可用即报错并附完整目录，不留半成品），再在首条消息投递前把选择写进新会话自己的日志——首回合即跑在指定模型上，且不改全局默认。
- **`session_models`**：列出本 Host 可在新会话运行的全部模型路由（provider、model、显示名、思考档位、默认选择），指定模型 / 档位前先查，免得模型去翻配置文件。
- **`/` 菜单「会话消息」**：选一个会话后，在输入框光标处插入会话 chip（`@` 引用同款渲染），不覆盖已输入文字；chip 提交时序列化为 `[目标会话：<标题>]`（英文界面为 `[Target session: <title>]`），模型据此组织正文并调用 `session_send`。菜单行名与全部界面文案随界面语言切换（英文 Session message）。
- **冷热两条投递路径**：热会话走收件箱 + `session-handoff` source（Web 端显示来源徽标），冷会话退回 `sessionController.prompt`。
- **回报协议**：`reply: true` 时在正文末尾追加回信地址；回信由对方用 `session_send` 发回，两边都不轮询对方。

## 本次工程化

- 源码迁移到 TypeScript：`src/index.ts`（Host 半）+ `src/client/index.ts`（Client 半），`tsc` 产出 `lib/`，`tsdown` 产出 `lib/client.js`（`window.__ModuleLoader__.load` 工厂）。
- 类型对齐 DeepSeek Harness `0.2.2-rc.5`；运行时零依赖，浏览器侧 React / Cordis 由 web shell 的冻结模块表提供。
- 补齐 `package.json` 元数据、`exports`、`files`、`publishConfig`、`prepublishOnly` 与 MIT `LICENSE`。
- 引入项目内决策记录体系 `docs/decisions/`（四态目录 + 双语规范 + 零依赖校验脚本 `check.mjs`），并列为首个版本的 4 条实现记录：TypeScript 迁移、零运行时依赖、npm 发布形态、client bundle 的 loader 契约。`check:decisions` 已接入 `prepublishOnly`。
- 冒烟测试改为针对构建产物 `lib/index.js` 运行。
- 发布走 GitHub Actions + npm Trusted Publishing（OIDC），推送 `v*` tag 触发。

## 验证

- `pnpm run typecheck`：通过。
- `pnpm run check:decisions`：4 条记录全部通过校验（文件名、Status 与目录一致、骨架段落、反规划残留、相对链接无死链）。
- `pnpm run build:all`：`lib/index.js`、`lib/client.js` 与本包 `d.ts` 全部产出。
- `pnpm test`：冒烟断言全绿，覆盖工具注册、列表过滤、按 id / 标题解析、歧义报错、自引用、子代理与空消息拒绝、冷会话 prompt 路径、热会话 relay 投递、`reply` 回信地址注入、`session_create` 的 Workspace 注册与首消息投递、`session_read` 的文本抽取与尾部截取。

## 已知限制

- 输入框中的 chip 在发出的消息里是纯文本（DSH 原生 `@` 引用同理）。
- 插件不保留会话关系台账：出站记录不落盘，入站来源仅以正文信封留存。
